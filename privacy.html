Privacy Policy

Effective 1 October 2026

This policy covers Shorts Uploader, a private tool Gut Punch Studio uses to upload videos to its own YouTube channel, and this website.

Who uses Shorts Uploader

Shorts Uploader is not offered to the public. The only account that signs in to it is Gut Punch Studio's own Google account.

YouTube API Services

Shorts Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data it accesses

  • Permission to upload videos to the signed-in YouTube channel.
  • Read-only access to the channel's name and ID, used only to confirm which channel uploads go to.

It does not read, collect or store viewer data, comments, analytics, emails or contacts.

How it stores and shares data

The sign-in token is stored only on the studio's own computer. Video files and their titles, descriptions and tags are sent to YouTube, and nowhere else. No data is sold or shared with third parties.

Removing access and deleting data

Access can be revoked at any time from the Google security settings page. Once access is revoked, the stored sign-in token stops working and is deleted from the studio's computer within 7 days. The channel name and ID that Shorts Uploader reads are shown on screen and never saved, so no other YouTube data needs deleting. Videos already uploaded stay on YouTube and are managed in YouTube Studio.

This website

This site uses no cookies, analytics or trackers. It is hosted on GitHub Pages, which may keep standard server logs as described in GitHub's privacy statement.
